## BATCH GENERATION INSTRUCTIONS

### For DALL-E 3:
1. Use prompts exactly as written
2. Request "pixel art" style explicitly
3. Specify 44x44 pixel resolution
4. Request transparent background
5. Ask for "isometric view"

### For Midjourney:
Add these parameters to each prompt:
```
--ar 1:1 --style raw --v 6 --quality 2
```

### For Stable Diffusion:
Model: "Pixel Art XL" or similar
Settings:
- Size: 512x512 (will downscale to 44x44)
- Steps: 50
- CFG Scale: 7
- Sampler: DPM++ 2M Karras

## POST-PROCESSING REQUIRED

After AI generation:
1. Resize to exactly 44x44 pixels
2. Ensure transparent background
3. Apply UO-appropriate color palette
4. Add isometric perspective if needed
5. Apply proper lighting (top-left)
6. Convert to indexed color (256 colors)
