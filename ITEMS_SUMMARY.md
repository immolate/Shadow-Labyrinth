## Usage Examples

### Creating Items in Code

```csharp
// Create a weapon
var photonRifle = new PhotonRifle();
photonRifle.Name = "Customized Photon Rifle";
photonRifle.Hue = 1266; // Can override color

// Create armor
var exosuit = new ExosuitChestplate();
World.AddEntity(exosuit);

// Create consumable
var healingSerum = new RegenerationSerum();
healingSerum.Amount = 5; // Stack of 5

// Create resource
var crystals = new QuantumCrystal();
crystals.Amount = 100; // 100 crystals
```

### Spawning Items for Players

```csharp
public void GiveStarterGear(Mobile player)
{
    // Give basic tech weapon
    var laserPistol = new LaserPistol();
    player.Backpack?.Add(laserPistol);

    // Give basic armor
    var nanoweaveVest = new NanoweaveBodysuit();
    player.Equip(nanoweaveVest);

    // Give healing items
    var medkit = new QuickHealPatch();
    medkit.Amount = 10;
    player.Backpack?.Add(medkit);

    // Give starter resources
    var energy = new EnergyCell();
    energy.Amount = 50;
    player.Backpack?.Add(energy);
}
```
